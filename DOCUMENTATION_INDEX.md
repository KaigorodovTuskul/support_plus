## 📌 Важные замечания

⚠️ **ПЕРЕД ДЕПЛОЕМ:**
- Замените `your-domain.com` на ваш домен во ВСЕХ файлах
- Измените SECRET_KEY в Django
- Используйте сильные пароли
- Установите DEBUG=False
- Настройте ALLOWED_HOSTS

⚠️ **БЕЗОПАСНОСТЬ:**
- Не коммитьте .env файлы в git
- Регулярно обновляйте зависимости
- Настройте автоматические бэкапы
- Используйте fail2ban

⚠️ **МОНИТОРИНГ:**
- Регулярно проверяйте логи
- Следите за использованием диска
- Настройте алерты при ошибках
